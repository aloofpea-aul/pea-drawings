1. ขอบเขตและวัตถุประสงค์ 1. Scope and objectives

แผ่นที่ 1 · SHEET 1 — ข้อ 1.1–1.4
  1. 1.1
    ให้ใช้กับระบบผลิตไฟฟ้าจากพลังงานแสงอาทิตย์ติดตั้งบนหลังคา ที่ไม่มีระบบแบตเตอรี่สำรองและไม่มีแหล่งกำเนิดไฟฟ้าชนิดอื่นร่วมด้วย สำหรับผลิตกระแสไฟฟ้าเพื่อใช้งานภายในส่วนผู้ใช้ไฟฟ้า และมีการเชื่อมต่อโครงข่ายระบบไฟฟ้าร่วมกับระบบจำหน่ายไฟฟ้าของ กฟภ.Applies to rooftop solar PV generating systems without battery storage and without any other generating source, producing electricity for use within the customer's premises and connected in parallel with the PEA distribution network.
  2. 1.2
    ข้อกำหนดนี้ใช้กับอินเวอร์เตอร์ที่ผ่านการทดสอบตามระเบียบ กฟภ. ว่าด้วยการเชื่อมต่อระบบโครงข่ายไฟฟ้าThis requirement applies to inverters tested in accordance with the PEA regulation on grid connection.
  3. 1.3
    ข้อกำหนดนี้ระบุถึงการเลือกขนาดสายเคเบิล สายดิน ตัวปรับค่า อุปกรณ์ป้องกันทางไฟฟ้า ป้ายเตือน ฯลฯ ทั้งด้านระบบไฟฟ้ากระแสตรง และระบบไฟฟ้ากระแสสลับIt covers selection of cable sizes, earthing conductors, converters, electrical protective devices, warning signs, etc., on both the DC and the AC side.
  4. 1.4
    หากไม่ได้ระบุไว้ในข้อกำหนดนี้ ให้ใช้ข้อกำหนดตามมาตรฐานของวิศวกรรมสถานแห่งประเทศไทยที่ประกาศใช้ในปัจจุบัน และ/หรือ ระเบียบ/ประกาศ/มาตรฐาน กฟภ. ที่เกี่ยวข้องWhere not specified here, the current standards of the Engineering Institute of Thailand (EIT) and/or the relevant PEA regulations / announcements / standards apply.

2. นิยาม 2. Definitions

แผ่นที่ 1 · SHEET 1 — ข้อ 2.1–2.12
  1. 2.1
    PV CELL หมายถึง อุปกรณ์พื้นฐานที่ทำหน้าที่เปลี่ยนพลังงานแสงอาทิตย์เป็นพลังงานไฟฟ้าPV cell: the basic device converting solar energy into electrical energy.
  2. 2.2
    PV MODULE หมายถึง ชุดประกอบที่เล็กที่สุดของ PV CELL ซึ่งเชื่อมต่อกันและมีการป้องกันทางกายภาพPV module: the smallest assembly of interconnected PV cells with physical protection.
  3. 2.3
    PV STRING หมายถึง วงจร PV MODULE หนึ่งชุดหรือมากกว่าต่ออนุกรมกันPV string: a circuit of one or more PV modules connected in series.
  4. 2.4
    PV SUB-ARRAY หมายถึง ส่วนย่อยของ PV ARRAY เกิดจากการต่อขนานของ PV STRINGPV sub-array: a part of a PV array formed by PV strings in parallel.
  5. 2.5
    PV ARRAY หมายถึง ชุดประกอบของ PV MODULE, PV STRING หรือ PV SUB-ARRAY ที่เชื่อมต่อกันทางไฟฟ้า และส่วนประกอบอื่นๆ จนถึงขั้วต่อสายด้านเข้า (INPUT) ไฟฟ้ากระแสตรงของอินเวอร์เตอร์PV array: the electrically interconnected assembly of PV modules, strings or sub-arrays and other components, up to the DC input terminals of the inverter.
  6. 2.6
    แรงดันเปิดวงจร PV MODULE หมายถึง แรงดันเปิดวงจรของ PV MODULE ที่สภาวะทดสอบมาตรฐาน ตามที่ระบุโดยผู้ผลิตในรายละเอียดของผลิตภัณฑ์PV module open-circuit voltage: the module open-circuit voltage at STC as stated by the manufacturer in the product data.
  7. 2.7
    กระแสลัดวงจร PV MODULE หมายถึง กระแสลัดวงจรของ PV MODULE หรือ PV STRING ที่สภาวะทดสอบมาตรฐาน ตามที่ระบุโดยผู้ผลิตในรายละเอียดผลิตภัณฑ์ หรือตามผู้ออกแบบPV module short-circuit current: the short-circuit current of the PV module or PV string at STC as stated by the manufacturer, or by the designer.
  8. 2.8
    สภาวะทดสอบมาตรฐาน (STANDARD TEST CONDITION : STC) หมายถึง สภาวะทดสอบมาตรฐานสำหรับการทดสอบมาตรฐาน PV CELL และ PV MODULE ประกอบด้วยStandard test condition (STC): the standard test condition for PV cells and modules, consisting of:
    • อุณหภูมิของ PV CELL ที่ 25 องศาเซลเซียสPV cell temperature 25 °C
    • ความเข้มแสงอาทิตย์ที่ตกกระทบบนระนาบของ PV CELL หรือ PV MODULE ต้องวัดได้ 1,000 วัตต์ต่อตารางเมตรirradiance on the plane of the PV cell or module 1,000 W/m²
    • สเปคตรัมของแสงอาทิตย์ต้องสอดคล้องกับมวลอากาศ (ATMOSPHERIC AIR MASS) ที่ 1.5solar spectrum corresponding to atmospheric air mass 1.5
  9. 2.9
    สายเคเบิล PV (PV STRING CABLE) หมายถึง สายเคเบิลที่ต่อจาก PV MODULE ใน PV STRING หรือเชื่อมต่อ PV STRING ดังกล่าวไปยังกล่องต่อสาย หรือกล่องรวมสาย หรือไปยังโหลดกระแสตรงPV string cable: the cable from the PV modules in a PV string, or connecting that string to a junction box, combiner box or DC load.
  10. 2.10
    กล่องต่อสายของ PV STRING (PV STRING JUNCTION BOX) หมายถึง กล่องต่อสายที่เชื่อมต่อ PV STRING เข้าด้วยกันPV string junction box: a box in which PV strings are connected together.
  11. 2.11
    กล่องรวมสาย PV STRING (PV STRING COMBINER BOX) หมายถึง กล่องต่อสายที่ใช้เชื่อมต่อ PV STRING เข้าด้วยกัน ซึ่งรวมชุดอุปกรณ์ป้องกันกระแสเกิน และ/หรือ อุปกรณ์ตัดวงจรPV string combiner box: a box connecting PV strings together and containing overcurrent protective devices and/or disconnecting devices.
  12. 2.12
    อุปกรณ์แปรผันกำลังไฟฟ้า (POWER CONVERTION EQUIPMENT : PCE) หมายถึง อุปกรณ์แปรผันกำลังไฟฟ้าที่ได้จาก PV ARRAY ให้มีความถี่และแรงดันที่เหมาะสมแก่โหลดที่เชื่อมต่อกับระบบไฟฟ้าของ กฟภ. เช่น อินเวอร์เตอร์ เป็นต้นPower conversion equipment (PCE): equipment converting the power from the PV array to a frequency and voltage suitable for loads connected to the PEA system, e.g. an inverter.
แผ่นที่ 2 · SHEET 2 — ข้อ 2.13–2.15
  1. 2.13
    ไดโอดกั้นกระแส (BLOCKING DIODE) หมายถึง ไดโอดที่ต่ออนุกรมกับ PV MODULE, PV STRING, PV SUB-ARRAY หรือ PV ARRAY เพื่อป้องกันไม่ให้กระแสไหลย้อนกลับไปยังอุปกรณ์ PV MODULE, PV STRING, PV SUB-ARRAY หรือ PV ARRAYBlocking diode: a diode in series with a PV module, string, sub-array or array to prevent reverse current flowing back into it.
  2. 2.14
    ไดโอดลัดข้าม (BYPASS DIODE) หมายถึง ไดโอดที่ต่อข้าม PV CELL หนึ่งเซลล์ หรือมากกว่าเพื่อให้กระแสไหลข้ามเซลล์ที่ถูกบังแสง (SHADING) หรือชำรุดBypass diode: a diode across one or more PV cells letting current bypass shaded or damaged cells.
  3. 2.15
    ตัวแปร ในข้อกำหนดนี้ให้ความหมายดังต่อไปนี้Symbols used in this requirement:

แผ่นที่ 3 · SHEET 3 — ข้อ 3.1–3.4
  1. 3.1
    การป้องกันกระแสเกิน (OVERCURRENT PROTECTION) ด้านกระแสตรง (DC SIDE) ที่วงจร PV STRING และวงจร PV ARRAY ต้องมีเครื่องป้องกันกระแสเกินตามที่ระบุไว้ในข้อ 3.2.1–3.2.2 ที่ด้านกระแสสลับ (AC SIDE) เครื่องป้องกันกระแสเกินต้องเป็นไปตามที่ระบุไว้ในข้อ 3.2.3Overcurrent protection on the DC side: PV string and PV array circuits shall have overcurrent protective devices as in 3.2.1–3.2.2; on the AC side the device shall be as in 3.2.3.
  2. 3.2
    ขนาดเครื่องป้องกันกระเสเกินให้พิจารณาดำเนินการตามข้อใดข้อหนึ่ง ดังนี้The overcurrent protective device shall be sized according to the following:

  2. 3.5.1

The connection of the grounding-electrode conductor to the electrode shall be by exothermic welding only.

    อาคารที่มีหรือเข้าข่ายต้องมีระบบป้องกันฟ้าผ่าสำหรับอาคาร ให้ต่อลงดิน PV MODULE FRAME และ ARRAY MOUNTING FRAME เข้ากับหลักดินโดยตรง หรือต่อผ่านบัสประสานศักย์เท่า (EQUIPOTENTIAL BONDING BUS) โดยไม่ต่อฝากสายดินเข้ากับอินเวอร์เตอร์ และแผงจ่ายไฟประธานIn buildings having or requiring an LPS, earth the PV module frames and array mounting frames directly to the earth electrode or via an equipotential bonding bus, without bonding the earthing conductor to the inverter and the main distribution board.
  3. 3.5.6
    หากระบบสายดินของ PV ARRAY อยู่ห่างจากระบบสายดินของระบบป้องกันฟ้าผ่าน้อยกว่า 1.80 เมตร กำหนดให้ต้องมีการต่อฝาก (BONDING) ระหว่างหลักดินของ PV ARRAY และหลักดินของระบบป้องกันฟ้าผ่า ด้วยสายตัวนำทองแดงขนาดเท่ากับสายดินของ PV ARRAY หรือสายดินของระบบป้องกันฟ้าผ่า (เลือกใช้ค่าที่มากกว่า)If the PV array earthing is less than 1.80 m from the LPS earthing, bond the PV array electrode to the LPS electrode with a copper conductor equal to the PV array or LPS earthing conductor, whichever is larger.
  4. 3.6
    การป้องกันแรงดันเกินจากฟ้าผ่า (PROTECTION AGAINST LIGHTNING OVERVOLTAGE)Protection against lightning overvoltage
  5. 3.6.1
    ประสานศักย์ให้เท่ากันทางไฟฟ้า (LIGHTNING EQUIPOTENTIAL BONDING : EB) การประสานโลหะแยกต่างหากเข้ากับระบบป้องกันฟ้าผ่า โดยการต่อตัวนำโดยตรง หรือผ่านอุปกรณ์ป้องกันเสิร์จ (SURGE PROTECTION DEVICE : SPD) เพื่อลดความต่างกันของศักย์ทางไฟฟ้าที่เกิดจากกระแสฟ้าผ่าLightning equipotential bonding (EB): bond separate metal parts to the LPS directly or via a surge protection device (SPD) to reduce potential differences caused by lightning current.
  6. 3.6.2
    หลีกเลี่ยงการต่อเป็นวงรอบ (AVOIDANCE OF WIRING LOOPS) โดยเดินสายเคเบิลกระแสตรงให้สายขั้วบวก และสายขั้วลบแต่ละวงจรอยู่ใกล้กันมากที่สุดเพื่อลดแรงดันช่วงก้าว (STEP VOLTAGE)Avoid wiring loops: run the positive and negative DC cables of each circuit as close together as possible to reduce step voltage.
  7. 3.6.3
    ติดตั้งอุปกรณ์ป้องกันเสิร์จ ใช้เพื่อจำกัดแรงดันเกินชั่วครู่ (TRANSIENT OVERVOLTAGE)Install surge protection devices to limit transient overvoltage.
  8. 3.7
    การเดินสายระหว่าง PV MODULE ให้ใช้สายไฟฟ้าที่ติดตั้งมาพร้อมกับ TERMINAL BOX ของ PV MODULE และต่อวงจรให้ถูกต้องแข็งแรง หรือใช้สายไฟฟ้าชนิด PHOTOVOLTAIC WIRE ขนาดไม่เล็กกว่าสายไฟฟ้าที่ติดตั้งมาพร้อมกับ PV MODULE โดยขั้วต่อสายต้องเป็นชนิด PV CONNECTOR หรือเทียบเท่าWiring between PV modules shall use the leads supplied with the module terminal box, correctly and firmly connected, or photovoltaic wire not smaller than the supplied leads, with PV connectors or equivalent.
  9. 3.8
    สายเคเบิลของวงจรกระแสตรงและกระแสสลับ ต้องไม่เดินในช่องเดินสายหรือกล่องต่อสายเดียวกัน และ/หรือ ระบบจ่ายไฟอื่นที่ไม่ใช่ระบบ PV (NON-PV SYSTEM)DC and AC circuit cables shall not share a raceway or junction box, nor with any non-PV system.
  10. 3.9
    สายเคเบิลกระแสตรงต้องเดินสายภายในช่องเดินสายโลหะ โดยข้อกำหนดการเดินสายต้องเป็นไปตามมาตรฐานการติดตั้งทางไฟฟ้าสำหรับประเทศไทย ฉบับที่มีการประกาศใช้ในปัจจุบันDC cables shall run in metal raceways, wired per the current Thai electrical installation standard.
  11. 3.10
    การติดตั้งสายไฟฟ้าด้านกระแสสลับต้องเป็นไปตามมาตรฐานการติดตั้งทางไฟฟ้าสำหรับประเทศไทย ฉบับที่มีการประกาศใช้ในปัจจุบันAC wiring shall follow the current Thai electrical installation standard.
  12. 3.11
    อาคารที่มีความสูงมากกว่า 15 เมตร การป้องกันฟ้าผ่าภายนอกให้เป็นไปตามมาตรฐานการป้องกันฟ้าผ่าของวิศวกรรมสถานแห่งประเทศไทย ในพระบรมราชูปถัมภ์ ฉบับที่มีการประกาศใช้ในปัจจุบันFor buildings taller than 15 m, external lightning protection shall follow the current EIT lightning protection standard.

  4. 4.16.1
